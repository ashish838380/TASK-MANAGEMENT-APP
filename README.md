# TaskFlow - Task Management App

TaskFlow is a full-stack task management application built using React, Node.js, Express.js, and MongoDB.

## Features

- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks
- View task statistics
- Track task completion progress
- Responsive design

## Technologies Used

### Frontend

- React.js
- Vite
- JavaScript
- HTML
- CSS

### Backend

- Node.js
- Express.js
- REST API
- CORS
- dotenv

### Database

- MongoDB
- Mongoose
- MongoDB Atlas
